# مجلد ملفات الاختبار (Test Files)

## الغرض
هذا المجلد مخصص لجميع ملفات الاختبار والتطوير في نظام TimePay.

## التنظيم
- **ملفات اختبار API**: ملفات PHP لاختبار وظائف API المختلفة
- **ملفات اختبار قاعدة البيانات**: ملفات لاختبار هيكل قاعدة البيانات
- **ملفات اختبار الأداء**: ملفات لقياس أداء النظام
- **ملفات اختبار التكامل**: ملفات لاختبار تكامل المكونات

## قواعد الاستخدام
1. **جميع ملفات الاختبار** يجب أن تبدأ بـ `test_`
2. **ملفات الاختبار المؤقتة** يجب حذفها بعد الانتهاء
3. **ملفات الاختبار المهمة** يمكن الاحتفاظ بها للرجوع إليها
4. **لا تضع ملفات الإنتاج** في هذا المجلد

## أمثلة على الملفات المسموحة
- `test_salary_calculation.php`
- `test_database_connection.php`
- `test_api_endpoints.php`
- `test_performance.php`

## أمثلة على الملفات غير المسموحة
- `unified_employees_api.php` (ملف إنتاج)
- `backup_system.php` (ملف إنتاج)
- `config.php` (ملف إنتاج)

---
**ملاحظة**: هذا المجلد لا يتم تضمينه في النسخ الاحتياطية للإنتاج.
