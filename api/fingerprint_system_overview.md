# نظام إدارة البصمة - نظرة عامة

## 🔧 الملفات الرئيسية:

### 1. **virtual_device_api.php** - الجهاز الافتراضي
- **الغرض**: محاكاة جهاز بصمة حقيقي للاختبار والتطوير
- **الوظائف**:
  - تسجيل دخول/خروج افتراضي
  - استيراد ملفات البصمة الحقيقية
  - مزامنة مع `attendance_logs`
- **قاعدة البيانات**: يحفظ في `fingerprint_attendance` ثم يزامن مع `attendance_logs`

### 2. **fingerprint_sync.php** - أجهزة البصمة الحقيقية
- **الغرض**: مزامنة البيانات من أجهزة البصمة الحقيقية
- **الوظائف**:
  - الاتصال بأجهزة ZKTeco, Suprema, Hikvision
  - مزامنة البيانات مباشرة
  - حساب ساعات العمل تلقائياً
- **قاعدة البيانات**: يحفظ مباشرة في `attendance_logs`

## 📊 تدفق البيانات:

### الجهاز الافتراضي:
```
المستخدم → virtual_device_api.php → fingerprint_attendance → مزامنة → attendance_logs
```

### الجهاز الحقيقي:
```
جهاز البصمة → fingerprint_sync.php → attendance_logs
```

## 🔄 المزامنة:

### تلقائية (أجهزة حقيقية):
- تحدث فوراً عند تسجيل البصمة
- لا تحتاج تدخل يدوي

### يدوية/تلقائية (جهاز افتراضي):
- زر "مزامنة مع سجلات الحضور"
- مزامنة تلقائية عند تسجيل دخول/خروج
- تحديث السجلات الموجودة

## 🗄️ هيكل قاعدة البيانات:

### جدول `fingerprint_attendance`:
- `ac_no` - رقم الموظف
- `employee_name` - اسم الموظف
- `attendance_date` - تاريخ الحضور
- `clock_in` - وقت الدخول
- `clock_out` - وقت الخروج
- `work_time` - ساعات العمل
- `department` - القسم

### جدول `attendance_logs`:
- `employee_id` - رقم الموظف
- `attendance_date` - تاريخ الحضور
- `check_in` - وقت الدخول
- `check_out` - وقت الخروج
- `work_hours` - ساعات العمل
- `overtime_hours` - ساعات إضافية
- `status` - حالة الحضور

## ⚙️ الإعدادات:

### ملف `fingerprint_settings_api.php`:
- تفعيل البصمة
- المزامنة التلقائية
- فترة المزامنة
- مهلة الاتصال
- محاولات إعادة المحاولة
- النسخ الاحتياطي

## 🚀 الاستخدام:

### للاختبار والتطوير:
1. استخدم الجهاز الافتراضي
2. سجل دخول/خروج
3. اضغط "مزامنة مع سجلات الحضور"

### للإنتاج:
1. أضف أجهزة البصمة الحقيقية
2. فعّل المزامنة التلقائية
3. البيانات ستظهر تلقائياً في `attendance_logs`
