# 🏗️ معمارية نظام البصمة

## 📋 نظرة عامة

نظام البصمة يتكون من ملفين رئيسيين لكل منهما غرض محدد:

## 🔧 الملفات الرئيسية

### 1. **`fingerprint_sync.php`** - أجهزة البصمة الحقيقية
**الغرض**: الاتصال المباشر بأجهزة البصمة الحقيقية

**الميزات**:
- ✅ اتصال TCP/IP مباشر مع الأجهزة
- ✅ دعم أجهزة ZKTeco, Suprema, Hikvision
- ✅ مزامنة تلقائية من ذاكرة الجهاز
- ✅ حساب ساعات العمل تلقائياً
- ✅ حفظ مباشر في `attendance_logs`

**كيفية العمل**:
```
جهاز البصمة الحقيقي → TCP/IP → fingerprint_sync.php → attendance_logs
```

**الوظائف**:
- `testConnection()` - اختبار الاتصال بالجهاز
- `syncData()` - مزامنة البيانات من الجهاز
- `updateAttendanceLog()` - تحديث سجلات الحضور
- `calculateWorkHours()` - حساب ساعات العمل

---

### 2. **`virtual_device_api.php`** - الجهاز الافتراضي + استيراد الملفات
**الغرض**: محاكاة جهاز البصمة + استيراد ملفات البصمة

**الميزات**:
- ✅ محاكاة جهاز بصمة للاختبار
- ✅ استيراد ملفات CSV/Excel من أجهزة البصمة
- ✅ معالجة البيانات العربية
- ✅ مزامنة مع `attendance_logs`
- ✅ تحويل تنسيقات مختلفة

**كيفية العمل**:
```
ملف البصمة → virtual_device_api.php → fingerprint_attendance → مزامنة → attendance_logs
```

**الوظائف**:
- `handleCheckIn()` - تسجيل دخول افتراضي
- `handleCheckOut()` - تسجيل خروج افتراضي
- `importFingerprintFile()` - استيراد ملفات البصمة
- `syncToAttendanceLogs()` - مزامنة مع attendance_logs
- `convertFingerprintData()` - تحويل تنسيقات البيانات

---

## 🔄 تدفق البيانات

### السيناريو 1: جهاز بصمة حقيقي
```
1. الموظف يضع إصبعه على الجهاز
2. الجهاز يرسل البيانات عبر TCP/IP
3. fingerprint_sync.php يستقبل البيانات
4. يتم حفظها مباشرة في attendance_logs
5. يتم حساب ساعات العمل تلقائياً
```

### السيناريو 2: استيراد ملف بصمة
```
1. تصدير ملف من جهاز البصمة (CSV/Excel)
2. رفع الملف عبر virtual_device_api.php
3. معالجة وتحويل البيانات
4. حفظ في fingerprint_attendance
5. مزامنة مع attendance_logs
```

### السيناريو 3: جهاز افتراضي (للاختبار)
```
1. اختيار موظف من القائمة
2. تسجيل دخول/خروج افتراضي
3. حفظ في fingerprint_attendance
4. مزامنة مع attendance_logs
```

## 📊 قاعدة البيانات

### جدول `attendance_logs` (الجدول الرئيسي)
```sql
- employee_id / AC-No. (رقم الموظف)
- attendance_date / date (تاريخ الحضور)
- check_in / check_in_time (وقت الدخول)
- check_out / check_out_time (وقت الخروج)
- work_hours (ساعات العمل)
- overtime_hours (ساعات إضافية)
- status (حالة الحضور)
```

### جدول `fingerprint_attendance` (للجهاز الافتراضي)
```sql
- ac_no (رقم الموظف)
- employee_name (اسم الموظف)
- attendance_date (تاريخ الحضور)
- clock_in (وقت الدخول)
- clock_out (وقت الخروج)
- work_time (ساعات العمل)
- department (القسم)
```

## 🚀 الخلاصة

- **`fingerprint_sync.php`**: للاتصال المباشر مع أجهزة البصمة الحقيقية
- **`virtual_device_api.php`**: للجهاز الافتراضي واستيراد الملفات
- **كلا الملفين**: يحفظان في `attendance_logs` في النهاية
- **النظام**: يدعم أعمدة مختلفة تلقائياً
- **البيانات العربية**: معالجة تلقائية للأرقام والتواريخ
